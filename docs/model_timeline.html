Hard-case reweighting — ปิดไป

commit สุดท้าย (9 ส.ค. 2026) · ไฟล์ทดลองลบแล้ว

ให้ loss ×3 กับ positive ที่เป็น hard-case หวังให้พยายามกับจุดยาก → F1 43.9% → 42.7% (hard-case ขึ้นนิดเดียวแต่ precision ลด + เฟ้อเส้น K/N 1.06→1.14)

บทเรียน: กำแพง hard-case ต้อง semantic understanding (panel-grid / VLM) ไม่ใช่ reweight — บน raw pixels ไม่มี feature แยก (effect d<0.5) → คงใช้ cnn_v5 ต่อไป
