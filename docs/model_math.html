สมการทั้งหมดของโมเดลตัดภาพเว็บตูน

จากโค้ดจริงใน train_v5.py + pipeline ใน core/ai_predictor.py — MobileNetV3-Small 512px + DP

1 Ground truth ฟรีจากโครงสร้างไฟล์

ทุกตอนที่ตัดแล้ว = label อัตโนมัติ ไม่ต้องเสียแรง label — รอยต่อคือขอบไฟล์ภาพ

รอยต่อ = เริ่มสะสมความสูงของแต่ละชิ้น (slice) $$g_i \;=\; \sum_{k=1}^{i} h_k, \qquad i = 1, 2, \dots, N-1$$ ชุดจุดตัดจริง (Ground Truth) $$G \;=\; \{\, g_1,\, g_2,\, \dots,\, g_{N-1} \,\}, \qquad |G| = N-1$$
$h_k$ = ความสูง (px) ของชิ้นภาพที่ k
$N$ = จำนวนแพเนลในตอน
$G$ = ชุดจุดที่คนตัดจริง

2 สร้าง training window (หน้าต่าง 512px)

เทรนให้ "เห็นการกระจายแบบเดียวกับตอนใช้งาน" — รอยต่อไม่ต้องอยู่กลางเสมอ + สอนว่าแค่ใกล้ไม่ใช่

Positive (รอยต่อ) — ครึ่งล่างชิ้น n ต่อครึ่งบนชิ้น n+1 + offset jitter $$w^{+} \;=\; \Big[\, \text{slice}_n^{(H-256-\delta\,:\,H)} \;;\; \text{slice}_{n+1}^{(0\,:\,256-\delta)} \,\Big], \qquad \delta \sim \mathcal{U}(-48,\, 48)$$ Negative near-miss — ใจกลางห่างจากรอยต่อ 60–280px (หลุมรอบรอยต่อ) $$w^{-}_{\text{near}} : \text{center}(w^{-}) \in \big[60,\, 280\big] \text{ px จาก } g_i$$ Negative กลางชิ้น — เนื้อหาจริง ไกลรอยต่อ $$w^{-}_{\text{mid}} : y_0 \sim \mathcal{U}\Big(\tfrac{512}{4},\, h_k - 512 - \tfrac{512}{4}\Big)$$
$\delta$ = เลื่อนรอยต่อจากกึ่งกลาง ±48px
อัตราส่วน 1 pos : 1.5 neg (ครึ่ง neg เป็น near-miss)
hflip p=0.5 กัน bias ซ้าย/ขวา
near-miss 60–280px นี้คือ "คูน้ำ" รอบรอยต่อ — กด score ข้างๆ ให้ peak คม แม้ผลจริงจะได้แค่ +0.9% ก็ตาม

3 โมเดล & ฟังก์ชันความน่าจะเป็น

MobileNetV3-Small 1.5M params — เบากว่า EfficientNet-B0 3.5 เท่า แต่บริบท 2 เท่า (512 vs 256px)

โครงสร้าง $$p(x) \;=\; \text{softmax}\big( \mathbf{W}^{\top} \cdot \text{MobileNetV3}_{512}(x) + \mathbf{b} \big), \qquad x \in \mathbb{R}^{3 \times 512 \times 512}$$ ความน่าจะเป็น "จุดนี้เป็นรอยต่อ" $$s(r) \;=\; p(\, y = 1 \mid x_r \,) \in [0,1]$$
Head: $\mathbf{W} \in \mathbb{R}^{576 \times 2}$ (จาก features 576 มิติ)
Normalize: ImageNet mean/std
$x_r$ = หน้าต่าง 512px ที่ครอบแถว r

4 Loss & Optimizer

Cross-Entropy + Label Smoothing ε = 0.05 $$\mathcal{L} \;=\; -\,(1-\varepsilon)\,\log p_y \;-\; \frac{\varepsilon}{C} \sum_{k=1}^{C} \log p_k, \qquad C=2$$ AdamW — lr 1e-4 · weight decay 1e-4 · AMP mixed precision $$\theta_{t+1} \;=\; \theta_t \;-\; \eta \cdot \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} \;-\; \eta\,\lambda_d \,\theta_t$$
$C$ = 2 คลาส (boundary / not)
$\eta$ = 1e-4 · $\lambda_d$ = 1e-4
12 epochs, batch 32 (RTX 3060 Ti ~1-2 ชม.)

5 Inference — สแกนทั้งตอน

merge ชิ้นภาพ → resize กว้าง 512 → รูดหน้าต่างทุก 16px (เร็วสุด เพราะ resize ทีเดียว ไม่ใช่ทีละ window)

Sliding window (stride s = 16) $$s(r) \;=\; p\big(y=1 \mid \text{window}(r)\big), \qquad r = 0,\, s,\, 2s,\, \dots,\, H-512$$ Smoothing — window 11 (peak คมกว่า 31) $$\tilde{s}(r) \;=\; \frac{1}{11} \sum_{j=-5}^{5} s(r + j)$$
smooth 31 → 11 คือการ tune ที่ได้ recall +14pp (68→84% ตาม metric เก่า) — peak แคบลง

6 Density prior — กดจุดที่เนื้อหาหนาทึบ

รอยต่อจริงส่วนใหญ่อยู่ใน gutter เบาบาง — ลดคะแนนของจุดที่ภาพหนาแน่น (ได้ +14.2pp!)

$$\hat{s}(r) \;=\; \tilde{s}(r) \;-\; \alpha_{den} \cdot \frac{d(r)}{d_{\max}}, \qquad \alpha_{den} \approx 0.75$$ $d(r)$ = ความหนาแน่นเนื้อหา (เช่น สัดส่วน pixel ที่ไม่ใช่ขาว) ของหน้าต่างที่แถว r
$\alpha_{den}$ = 0.75 (sweep 3 รอบได้ค่าดีสุด)
25.9% → 40.1% fixed-N ±50

7 จับจุดสูงสุด + ปรับตำแหน่งละเอียด

Local peaks เหนือเกณฑ์ $$P \;=\; \big\{\, r : \hat{s}(r) \ge \theta,\; \hat{s}(r) \text{ เป็น local max},\; |r_i - r_j| \ge d_{\min} \,\big\}, \qquad \theta = 0.30\!-\!0.35$$ Refine — เลือกแถวที่เนื้อหาเบาที่สุดใน ±10px ของ peak $$r^{*} \;=\; \arg\min_{r \,\in\, [p-10,\, p+10]} d(r)$$
$\theta$ ต่ำ = เส้นเยอะ · สูง = สะอาด
$d_{\min}$ ≈ 35 (กันจุดติดกัน)
ใช้จริง: θ 0.3–0.35, smooth 11

8 เลือกชุดเส้นด้วย Dynamic Programming ⭐

หัวใจที่ทำให้ +10pp — แทนที่จะยิงทุก peak ให้เลือกชุดที่ "รวมคะแนนสูงสุด" + บังคับระยะห่างเหมือนคน

Count-free (งานจริง) — AI ตัดสินใจจำนวนเอง ปรับ λ ต่อเส้น $$\max_{r_1 < r_2 < \cdots < r_K} \; \sum_{i=1}^{K} \hat{s}(r_i) \;-\; \lambda \cdot K \qquad \text{s.t. } r_{i+1} - r_i \ge d_{\min}$$ Fixed-N — ถ้ารู้จำนวนจริง N ต้องเลือก N เส้น $$\max \sum_{i=1}^{N} \hat{s}(r_i) \qquad \text{s.t. } r_{i+1} - r_i \ge d_{\min},\; N = |G|$$ สมการ recurrence ของ DP $$V(i, k) \;=\; \max\!\big( V(i-1, k),\; V(i-d_{\min},\, k-1) + \hat{s}(r_i) \big)$$
$\lambda$ = 0.8 (balance recall/prec)
$d_{\min}$ = 400 (production) / 1500 (eval best)
greedy 41% → DP 51.2%
ผลสำคัญ: count-free F1 ≈ 50.5% ≈ fixed-N 51.2% → โมเดล "นับจำนวนเองได้" แล้ว คอขวดไม่ใช่การนับ

9 Metric จริงที่ใช้ตัดสิน — fixed-N ±50

ตัวเลข 87% เดิมเกินจริงเพราะยิงเส้นเยอะก็ได้สูง — มาตรฐานใหม่ = จำนวนเท่ากัน + แต่ละเส้นห่าง ≤50px

1:1 match — เส้นทายชนกับรอยต่อจริงภายใน ±50px $$\text{matched} \;=\; \Big| \big\{\, \hat{r} \in \hat{R} : \exists\, g \in G,\; |\hat{r} - g| \le 50 \,\big\} \Big|$$ Fixed-N accuracy $$\text{acc} \;=\; \frac{\text{matched}}{|G|}$$ Count-free F1 $$R = \frac{\text{matched}}{|G|}, \qquad P = \frac{\text{matched}}{|\hat{R}|}, \qquad F1 = \frac{2\,P\,R}{P+R}$$
$\hat{R}$ = ชุดเส้นที่โมเดลทาย
$G$ = รอยต่อจริง
v5 final: acc 43.7% · F1 43.9% (val ใหม่)
