# Final Verdict: GBM vs CNN Boundary Model (3-Round Decision)

> ## ⚠️ คำเตือน (อัปเดต 2026): ตัวเลขด้านล่าง "เกินจริง"
> ตัวเลข recall 84-87% ในไฟล์นี้ใช้ metric เดิมที่ **ให้จำนวนเส้นอิสระ + tolerance ±100/200px**
> → โมเดลยิงเส้นเยอะก็ได้ recall สูง (ตัวเลขหลอก)
>
> **metric ที่ถูกต้อง (ตามที่ user กำหนดใหม่): `fixed-N ±50px`** — จำนวนเส้น = ของจริงทุกตอน, แต่ละเส้นต้องห่าง ≤ 50px (1:1 match)
> **ตัวเลขจริง:** CNN r3 = 40.1% / r4 + DP = **51.2%** / count-free F1 ≈ 50.5%
> → บทสรุป "CNN ชนะ GBM" ยังคงถูก แต่ช่องว่างแคบกว่าที่คิดมาก
> **รายละเอียดทั้งหมดอยู่ใน `../TRAINING_GUIDE.md` หมวด 9**

## สรุปผลการตัดสินใจอัตโนมัติ 3 รอบ (รอบแรก — ยังใช้ metric เก่า)

**วิธีทดสอบ:** 80/20 split แบบ deterministic (SEED=7, train 169 ตอน / held-out 42 ตอน)
ทั้ง 2 โมเดลเทรนบน 80% ชุดเดียวกัน + ประเมินบน 20% ชุดเดียวกัน (ยุติธรรม 100%)

### ผลลัพธ์ (recall @ ±100/±200px)

| รอบ | CNN recall | GBM recall | delta | ผล |
|---|---|---|---|---|
| R1 (เทรน 15ep, th=0.3, smooth=31) | 68.7% | 66.8% | +1.9% | borderline → เข้า R2 |
| **R2 (tuned: th=0.3, smooth=11)** | **84.7%** | 71.4% | **+13.3%** | **CNN ชนะ** |
| **R3 (ยืนยัน seed 1234, 10ep, tuned)** | **87.2%** | 71.4% | **+15.8%** | **CNN ชนะซ้ำ** |

### สรุป
- **CNN ชนะขาดทั้ง 2 รอบที่ tuned (+13~16%)** — ผลไม่ใช่เรื่องบังเอิญ (2 seeds ต่างกัน)
- เกณฑ์เดิม: delta ≥ +10% → CNN ชนะ → **หยุดได้ตามแผน** (ครบ 3 รอบ)

### จุดที่ CNN เก่งกว่า (per-series, R2)
| เรื่อง | CNN | GBM | ต่าง |
|---|---|---|---|
| 1 | 93.6% | 93.0% | +0.6% |
| be-the-actor | 95.3% | 95.3% | 0% |
| black-corporation-joseon | 88.6% | 73.0% | +15.6% |
| evolution-from-the-big-tree | 85.8% | 80.8% | +5.0% |
| **i-will-raise** (transfer แย่สุดเดิม) | **70.5%** | **38.9%** | **+31.6%** |

### ต้นทุน (ที่วัดจริง)
| ตัวชี้วัด | GBM | CNN |
|---|---|---|
| เทรน (ครั้งเดียว) | ~2 นาที | ~2 ชม. (15ep) |
| inference/ตอน | ~1.1s | ~30-40s |
| precision (R2 tuned) | 53.8% | 51.7-59.3% (ขึ้นกับ th) |

### ข้อควรรู้ก่อน deploy
1. CNN เก่งเรื่องใหม่/ต่างสไตล์ (i-will-raise +31.6%) = รองรับ "เรื่องใหม่" จริงตามที่ต้องการ
2. เรื่องที่ GBM เก่งอยู่แล้ว CNN ก็เก่งพอๆ กัน (95%)
3. ราคาที่จ่าย = inference ช้า ~30 เท่า → ต้อง optimize (ลด windows / ใช้ batch ใหญ่ / หรือ pruning)
4. CNN precision แปรตาม threshold → เลือก th ตามเป้า (recall สูง → th ต่ำ, precision สูง → th สูง)

## ไฟล์สำคัญ

## คำแนะนำขั้นต่อไป
- **ใช้ CNN r3 (tuned th=0.3, smooth=11) เป็นโมเดลหลัก** สำหรับเรื่องใหม่
- **ใช้ GBM เป็น fallback เร็ว** (หรือ hybrid: GBM เร็วแล้ว CNN ตรวจซ้ำเฉพาะจุดน่าสงสัย)
- **optimize CNN inference** ก่อนใช้งานจริง (ตอนนี้ 30-40s/ตอน ช้าเกินไป)
- ระบบสะสมเรียนรู้: เก็บ "แก้เส้น" → fine-tune CNN ต่อ (แต่ต้องระวังเวลาเทรน 2 ชม.)
